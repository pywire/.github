## 🚀 Quick Start

If you already have [uv](https://docs.astral.sh/uv/) installed, you can get started instantly:

```sh
uvx create-pywire-app
```

If you don't have `uv`, but have `npx` installed you can use that instead:

```sh
npx create-pywire-app
```

If you don't have `uv` or `npx` installed or aren't sure, use our installer script which handles the setup for you:

### macOS / Linux
```sh
curl -fsSL pywire.dev/install | sh
```

### Windows (PowerShell)
```powershell
irm pywire.dev/install.ps1 | iex
```
